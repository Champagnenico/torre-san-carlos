# Guía para contribuir
 
¡Gracias por tu interés en mejorar el proyecto! Para mantener el orden, por favor seguir estos pasos:
 
## Cómo reportar errores (Issues)
* Revisa antes si el error ya fue reportado en la pestaña **Issues**.
* Explica qué esperabas que ocurriera, qué ocurrió en realidad y cómo reproducir el fallo.
 
## Cómo enviar cambios (Pull Requests)
1. Haz un **Fork** del repositorio.
2. Crea una rama nueva para tu cambio (`git checkout -b mejora-ejemplo`).
3. Asegúrate de que tu código funcione y mantenga el estilo del proyecto.
4. Abre un **Pull Request** explicando claramente qué problema resuelve tu aporte.
